# 01. 프로젝트 기획서

## 1. 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | daily-english (서비스명: 오늘의 영어) |
| 형태 | 앱인토스 미니앱, WebView 방식 |
| 유형 | 비게임 (학습) |
| 개발 인원 | 1인 |
| 착수일 | 2026-10-21 |

## 2. 배경

- 토스 앱 안에서 바로 열리는 미니앱은 설치 없이 사용자를 만날 수 있다.
- 영어 학습 앱은 많지만 개발 현장 영어(에러 메시지, 커밋, PR 리뷰, 기술 문서)를 짧게 다루는 앱은 드물다.

## 3. 목표

1. 하루 1~2분, 5문제로 끝나는 학습 습관 도구를 만든다.
2. 점수 경쟁 없이 개인 레벨 성장만으로 동기를 준다.
3. 앱인토스 심사를 통과해 실제로 출시한다.

## 4. 범위

### 포함 (MVP)
- 날짜별 5문제 객관식 퀴즈와 즉시 해설
- XP, 레벨, 연속 학습일(streak)
- 레벨별 난이도 조절
- 기기 저장 (토스 앱 안에서는 SDK 저장소)

### 제외 (MVP 이후 검토)
- 랭킹, 친구 비교, 점수 공유
- 토스 로그인과 서버 동기화
- 오답 복습
- 광고·인앱결제

## 5. 타깃 사용자

- 1차: 영어 문서와 커뮤니케이션이 잦은 주니어 개발자, 개발 직군 취업 준비생
- 2차: 짧게 영어를 접하고 싶은 일반 토스 사용자 (일상 영어 문제로 대응)

## 6. 차별점

- 문제의 절반을 개발 실무 영어로 구성
- 하루 분량이 정해져 있어 부담이 적음
- 랭킹 대신 개인 레벨이라 비교 스트레스가 없음

## 7. 리스크

| 리스크 | 영향 | 대응 |
|--------|------|------|
| 문제 품질 오류 | 신뢰도 하락 | 생성 후 사람 검수, 출처 확인 |
| 문제 수 부족 (현재 160개, 하루 5개면 32일분) | 재방문 사용자 이탈 | 생성 파이프라인으로 계속 확충 |
| 기기 저장 데이터 유실 | 레벨 초기화 | SDK 저장소 사용, 이후 토스 로그인 + 서버 저장 검토 |
| 앱인토스 심사 반려 | 출시 지연 | 비게임 출시 가이드 대응 ([16](16_앱인토스_연동_조사.md)) |
| 게임 유형으로 분류될 가능성 | 심사 항목 변경 | 점수·랭킹 요소 배제 유지 |

## 8. 일정 개요

세부 일정은 [14_WBS](14_WBS.md)를 따른다.

| 단계 | 기간 |
|------|------|

| MVP 개발·검증 | 1~2주차 |
| 문제 확충·검수 | 2~3주차 |
| 앱인토스 연동·심사 | 3~4주차 |
