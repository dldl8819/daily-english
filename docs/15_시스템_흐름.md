# 15. 시스템 흐름

## 1. 앱 진입 [구현]

```mermaid
sequenceDiagram
    actor U as 사용자
    participant T as 토스 앱 WebView
    participant C as DailyChallenge
    participant S as lib/storage
    participant SDK as 앱인토스 SDK
    participant D as lib/daily

    U->>T: 미니앱 열기
    T->>C: 정적 HTML·JS 로드 (빈 화면)
    par 진행 상황
        C->>S: loadProgress()
        S->>SDK: Storage.getItem(key)
        SDK-->>S: JSON 또는 null
        Note over S: null이면 localStorage 값 사용
        S-->>C: Progress
    and 오늘 날짜
        C->>S: todayKey(dateKey)
        S->>SDK: Environment.getServerTime()
        SDK-->>S: ms (미지원이면 기기 시계)
        S-->>C: "2026-10-21"
    end
    alt 오늘 완료함
        C-->>U: 레벨 카드 + 결과 화면
    else 오늘 시작한 풀이 있음
        C-->>U: 레벨 카드 + 답하지 않은 첫 문제
    else 처음
        C->>D: startAttempt(progress, QUESTIONS, today)
        D-->>C: attempt { ids 5개, picks [] }, seen 갱신
        C->>S: saveProgress()
        C-->>U: 레벨 카드 + 1번 문제
    end
```

토스 앱 밖(일반 브라우저)에서는 SDK 호출 없이 localStorage와 기기 시계만 쓴다.

## 2. 문제 풀이와 완료 [구현]

```mermaid
sequenceDiagram
    actor U as 사용자
    participant Q as Quiz
    participant C as DailyChallenge
    participant D as lib/daily
    participant S as lib/storage

    loop 문제 5개
        U->>Q: 선택지 클릭
        Q->>C: onPick(index, choice)
        C->>D: recordPick(progress, index, choice)
        C->>S: saveProgress()
        Q-->>U: 정답/오답 색, 해설
        U->>Q: 다음 문제
    end
    U->>Q: 결과 보기
    Q->>C: onFinish()
    C->>D: countCorrect(questions, picks)
    C->>D: completeDay(progress, today, correct, 5)
    C->>S: saveProgress()
    C-->>U: 레벨 카드 갱신 + 결과 화면
```

## 4. 문제 선택 흐름

```mermaid
flowchart TD
    A[startAttempt 호출] --> B{오늘 attempt가 있고<br/>문제가 모두 은행에 있음?}
    B -- 예 --> Z[그대로 사용]
    B -- 아니오 --> C[레벨 = levelFromXp xp]
    C --> D[difficultyMix 레벨 → 난이도 5개]
    D --> E[문제 정렬: 안 본 문제 먼저, 날짜 해시 순]
    E --> F[슬롯마다: 난이도·분류 일치 & 안 봄<br/>→ 난이도 일치 & 안 봄<br/>→ 가장 가까운 난이도]
    F --> G[attempt 저장, seen에 추가]
```

## 5. 진행 상황 갱신 흐름

```mermaid
flowchart LR
    A[완료 이벤트] --> B{오늘 이미 완료?}
    B -- 예 --> Z[변경 없음]
    B -- 아니오 --> C{lastDate가<br/>어제?}
    C -- 예 --> D[streak + 1]
    C -- 아니오 --> E[streak = 1]
    D --> F[xp += 맞힌 수×10 + 5]
    E --> F
    F --> G[lastDate = 오늘<br/>today = 결과]
    G --> H[(localStorage + SDK Storage)]
```

## 6. 서버 연동 후 흐름 [계획]

```mermaid
sequenceDiagram
    actor U as 사용자
    participant W as WebView
    participant L as TossAuth.login
    participant A as API 서버
    participant DB as DB

    U->>W: 미니앱 열기
    W->>L: 로그인
    L-->>W: authorizationCode, referrer
    W->>A: 세션 발급 요청
    A->>DB: users 조회/생성
    W->>A: GET /me/progress
    opt 서버 기록 없음 & 기기 기록 있음
        W->>A: POST /me/progress/import
    end
    W->>A: GET /daily?date=오늘
    A-->>W: 문제 (정답 제외)
    loop 문제 5개
        W->>A: POST /daily/{date}/answers
        A->>DB: answers 저장
        A-->>W: 채점, 해설
    end
    W->>A: POST /daily/{date}/complete
    A->>DB: daily_results, user_progress 갱신
    A-->>W: xp, level, streak
```

서버 연동 후에는 채점과 XP 계산이 서버로 옮겨져 일반 브라우저에서의 기기 시간 조작 문제([12_상세_설계](12_상세_설계.md) 8장)도 해소된다.
