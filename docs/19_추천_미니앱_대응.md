# 19. 추천 미니앱 선정 기준 대응

근거: [토스 앱에 노출하기](https://developers-apps-in-toss.toss.im/guide/exposure) (2026-10-22 노출 정책 변경). 추천 미니앱은 UX·실사용 지표·리뷰·성능 네 기준을 **모두** 충족해야 하고, 추천되면 미니앱 스토어·전체탭·검색에서 우선 노출된다.

## 기준 1. UX 원칙

| 원칙 | 체크리스트 | 상태 | 근거 |
|------|-----------|------|------|

| | 동의창은 관련 기능 선택 뒤 | ✅ | 알림은 설정 > 학습 알림 설정 > "알림 받기"를 눌러야 동의창 |
| | 요청 화면만 보고 이유를 알 수 있음 | ✅ | "매일 저녁 7시에 오늘의 문제가 열렸다고 알려 드려요" |

| | 추가 광고는 보상을 원할 때만 선택 | ✅ | 보상형 광고는 "광고 보고 5문제 더 풀기"를 눌러야 재생, 얻는 것("끝까지 보면 열려요")을 미리 안내 |
| 3) 디자인 | 제목·설명·결과 구분 | ✅ | 제목 22px, 문제 20px, 보조 14px |

## 기준 2. 실사용 지표

### 앱에서 기록하는 이벤트 (`src/lib/analytics.ts`, `Analytics.log`)

| 이벤트 | 시점 | 파라미터 |
|--------|------|----------|
| `daily_complete` | 오늘 5문제 완료 | correct, total, level, streak |
| `bonus_open` | 보너스 5문제 열림 | source (share·ad) |
| `bonus_complete` | 보너스 5문제 완료 | source, correct |
| `share_app` | 친구에게 알리기 공유 창 완료 | - |
| `item_save` | 다시 볼 문장·단어 저장 | kind |
| `reminder_agree` | 학습 알림 동의 | - |
| `{화면}_screen` | 화면 진입 (home·saved·settings·review) | - |

- 개인정보는 보내지 않는다. 토스 앱 밖에서는 기록하지 않는다.
- 데이터는 출시 다음 날부터 콘솔 '분석 > 이벤트'에 보인다.

### 콘솔 핵심 지표

이 앱은 "일상 기록 앱"처럼 **재방문율**이 주요 지표다. 전환 지표는 콘솔 MCP(`event_act_type_set`)로 등록했고, 활성 지표는 MCP로 다룰 수 없어 콘솔 웹(미니앱 → 핵심 지표)에서 등록한다.

| 구분 | 설정 | 이벤트 | 상태 |
|------|------|--------|------|
| 활성 지표 | 템플릿 7일 재방문율 (`RETENTION_D7`) | - | 콘솔 웹에서 등록 |
| 전환 지표 · 대표 | 오늘 5문제 완료 (id 57669) | `daily_complete` | 2026-10-22 등록, 10-23부터 대표 |
| 전환 지표 · 보조 | 보너스 문제 완료 (id 57671) | `bonus_complete` | 2026-10-22 등록 |
| 전환 지표 · 보조 | 친구에게 알리기 (id 57673) | `share_app` | 2026-10-22 등록 |

- 알림 템플릿이 정상화되면 `share_app` 대신 템플릿 "알림 동의"(`NOTIFICATION_AGREEMENT`)로 바꾸는 것을 검토한다. 전환 지표는 3개까지를 권장한다.
- 지표 값은 등록 다음 날부터 집계된다. 대표는 지울 수 없고 바꾸기(다음 날 적용)만 된다.

## 기준 3. 리뷰

- `Review.request()`를 **오늘 5문제를 마친 순간**, 연속 학습 3일째와 7일마다, 3문제 이상 맞혔을 때만 부른다 (`shouldAskReview`). 하루에 한 번만 해당 시점이 온다.
- 노출 여부·작성 여부와 상관없이 흐름은 그대로다(문서: 결과에 따라 흐름·보상을 바꾸지 말 것).
- 콘솔 '평점 및 리뷰'에서 같은 불만이 반복되면 그 부분부터 고친다.

## 기준 4. 성능

- 정적 번들(서버 없음), 첫 화면 JS 약 115 kB, 런타임 네트워크 요청은 SDK 호출뿐.
- 실기기 점검 항목: 첫 진입 시간, 문제 풀이 반응, 보너스 광고 로드 대기(광고 준비 중 버튼 비활성).
