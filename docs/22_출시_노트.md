# 22. 출시 노트

번들마다 콘솔 검수 요청에 넣은 출시 노트를 모은다. 새 노트는 검수 요청 전에 여기에 먼저 쓰고, 검수 요청에는 이 파일의 문안을 그대로 넣는다.

- 기준일: 2026-11-26
- 출처: 콘솔 번들 목록(`bundle_list`의 `releaseNote`, `lastDeployedAt`)과 검수 요청 목록(`review_list`), 2026-11-26 조회. 시각은 모두 KST다.

## 1. 쓰는 법

- 사용자가 읽는 글이다. 해요체로 쓰고, 무엇이 바뀌었는지 구체적으로 쓴다.
- 1,000자 이하로 쓴다(`bundle_submit_review`의 `releaseNotes` 한도).
- 테스트만 하고 출시하지 않은 번들은 여기에 적지 않는다. 그 변경은 다음 출시 노트에 합친다.
- 순서: 문안 작성 → 검수 요청(요청 시각 기록) → 승인(승인 시각 기록) → 콘솔 웹 '앱 출시'에서 '출시하기'(출시 시각 기록). 승인돼도 자동으로 출시되지 않는다.
