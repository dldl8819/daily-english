# 04. 기능 명세서

## F-01. 오늘의 문제 선택 [구현]

| 항목 | 내용 |
|------|------|
| 관련 요구사항 | FR-01, FR-02, FR-14 |
| 입력 | 문제 은행(`questions.json` 1,425개, 서버 모드는 `questions.extra.json` 추가 문항까지), 오늘 날짜 키, 맞춤 문제 설정(F-15), 사용자 레벨, 이미 본 문제 ID |
| 처리 | 학습 목적의 분류에서만, 레벨별 난이도 구성(F-09)에 맞춰 하루 목표만큼 고른다. 안 본 문제를 먼저 고르고, 목적의 분류가 둘이면 번갈아 고른다. 같은 조건이면 날짜로 정해지는 순서를 따른다. |
| 고정 | 하루를 시작할 때 고른 문제 ID를 `attempt`에 저장한다. 이후 문제 은행이나 레벨이 바뀌어도 그날 문제는 그대로다. |
| 출력 | 문제 5개 |
| 예외 | 원하는 난이도의 새 문제가 떨어지면 가까운 난이도의 새 문제를 먼저 낸다(2026-10-25 바꿈, 하루 20문제씩 1년 동안 새 문제를 내기 위해서다. [20_문제_은행_확장](20_문제_은행_확장.md)). 새 문제가 모두 떨어졌을 때만 본 문제에서 고르고, 이때는 틀린 문제·오래전에 본 문제가 먼저다. 고정한 문제가 은행에서 빠졌으면 다시 고른다. |
| 구현 | `pickDaily()`, `startAttempt()`, `attemptQuestions()` in `src/lib/daily.ts` |

## F-02. 문제 풀이 [구현]

| 항목 | 내용 |
|------|------|
| 관련 요구사항 | FR-03, FR-04, FR-05, FR-12 |
| 입력 | 사용자의 선택지 클릭 |
| 처리 | 고른 답을 `attempt.picks`에 바로 저장한다. 이미 답한 문제는 바꿀 수 없다. |
| 출력 | 정답 선택지는 초록, 오답으로 고른 선택지는 빨강. 해설, 정답을 채운 문장의 "문장 해석"(해석이 있는 문항만), "다음 문제" 버튼. 마지막 문제에서는 "결과 보기". 분류(개발자/직장/학교/토익/일상)와 난이도(기초/중급/심화) 태그. |
| 해석 | 해석은 정답을 알려 주므로 답한 뒤에만 보인다. 서버 모드에서는 답하기 전에 받는 문제에 해석이 없고, 채점 결과로 받는다 (`Translation` 컴포넌트) |
| 이어 풀기 | 풀이 중 앱을 닫았다 열면 답하지 않은 첫 문제부터 이어서 푼다. |
| 구현 | `Quiz` 컴포넌트, `recordPick()` |

| 제약 | 정기 발송 템플릿은 미니앱 출시(운영 중) 후에만 만들 수 있다. 21~08시는 방해 금지라 그 사이 예약은 다음 날 08시로 밀린다 |

## F-14. 5문제 더 풀기 (공유·광고 보너스) [구현]

| 항목 | 내용 |
|------|------|
| 조건 | 오늘 기본 5문제를 마친 뒤, 결과 화면 아래 "5문제 더 풀기" 영역에서 연다 |
| 친구에게 알리기 | `Share.createLink({ path: 'intoss://english-bite' })`로 토스 공유 링크를 만들고 `Share.sendMessage`로 공유 창을 연다. 오류 없이 끝나면 지급. 친구가 실제로 받았는지는 알 수 없다 |
| 광고 보기 | 보상형 광고. 화면에 들어오면 `loadFullScreenAd`로 미리 불러 두고(미리 로드 의무), 사용자가 누를 때 `showFullScreenAd`. `userEarnedReward`(끝까지 시청)에서만 지급하고, 중간에 닫으면 다시 불러 둔다 |

## F-15. 맞춤 문제 (배우는 이유·실력·하루 목표) [구현]

| 항목 | 내용 |
|------|------|
| 묻는 때 | 처음 들어왔을 때(이전 버전 사용자 포함) 오늘의 문제 자리에 보여 준다. 오늘 문제를 이미 풀기 시작했거나 마쳤으면 다음 날 묻는다. 고르기 전에는 오늘의 문제를 고정하지 않는다 |
| 방식 | 한 화면에 질문 하나. 보기를 누르면 바로 다음 질문으로 넘어간다(보기는 버튼, 고른 보기는 `aria-pressed`). "이전"과 진행 표시(1/3). 질문이 바뀌면 질문 제목으로 포커스 |
| 1. 배우는 이유 | 소통 → 일상 + 직장 / 경력 개발 → 쓰는 곳을 한 번 더 묻는다: 개발 업무(개발자 + 직장), 일반 업무(직장 + 일상), 토익 점수(토익 + 직장) / 취미·여행 → 일상 / 학업 → 학교 + 토익 |
| 2. 실력 | 기초부터 / 어느 정도 / 자신 있어요 → 시작 레벨 1 / 3 / 5. 문제 난이도에만 쓰고 XP·레벨 표시는 그대로. XP 레벨이 더 높으면 XP 레벨을 쓴다 |
| 3. 하루 목표 | 5 / 10 / 15 / 20문제. 이만큼 풀어야 오늘 학습 완료(연속 학습일 기준). 난이도 구성은 5문제 묶음을 되풀이. XP 규칙은 그대로(정답 10, 목표 완료 +5). 보너스는 목표와 상관없이 5문제 |
| 바꾸기 | 설정 > 맞춤 문제 설정에서 같은 질문으로. 오늘 문제를 하나도 안 풀었으면 바로 다시 고르고, 풀기 시작했으면 다음 날부터 |
| 이전 버전 | 20261022-7의 학습 목적은 같은 문제가 나오는 설정으로 옮긴다(개발자·직장인·토익 → 경력 개발, 학생 → 학업, 일상·여행 → 여행). 하루 목표는 5문제 |
