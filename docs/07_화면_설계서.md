# 07. 화면 설계서

앱은 한 페이지(`/`)이고, 상단 레벨 카드 아래 영역이 상태에 따라 바뀐다.

## 공통 헤더

```
┌──────────────────────────────┐
│ 오늘의 영어                   │  h1
│ 하루 5문제, 1~2분이면 끝나요   │  .sub
└──────────────────────────────┘
```

## S-00. 화면 모드 선택 [구현]

```
화면
┌────────┐ ┌────────┐ ┌────────┐
│ ✓ 기본 │ │ 고대비 │ │ 어둡게 │
└────────┘ └────────┘ └────────┘
```

- 헤더 바로 아래. 라디오 묶음이라 스크린리더에서 "화면, 기본, 라디오 버튼, 3개 중 1번째, 선택됨"처럼 읽힌다.
- 고르면 바로 화면 전체와 내비게이션 바가 바뀐다.

## S-01. 레벨 카드 [구현]

```
┌──────────────────────────────┐
│ Lv.2               30 / 120 XP│
│ ██████░░░░░░░░░░░░░░░░░░░░░░ │
│ 3일 연속으로 풀었어요          │
└──────────────────────────────┘
```

| 요소 | 데이터 | 규칙 |
|------|--------|------|
| 레벨 | `levelProgress(xp).level` | "Lv.N" |
| XP | current / needed | 현재 레벨 안에서의 값 |
| 진행 바 | current / needed × 100% | 최대 100% |
| streak 문구 | `visibleStreak()` | 0이면 "오늘 첫 문제를 풀어 보세요" |

## S-02. 문제 풀이 [구현]

### 답하기 전
```
┌──────────────────────────────┐
│ 2 / 5                         │
│ [개발자 영어] [기초]           │
│ Let's ___ the meeting to      │
│ Thursday.                     │
│ ┌──────────────────────────┐ │
│ │ put on                    │ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ push back                 │ │
│ └──────────────────────────┘ │
│ ... (선택지 4개)              │
└──────────────────────────────┘
```

### 답한 후
```
│ ┌──────────────────────────┐ │
│ │ put on          (빨강)    │ │  ← 사용자가 고른 오답
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ push back       (초록)    │ │  ← 정답
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ 'push back'은 일정을 뒤로 │ │  해설
│ │ 미룬다는 뜻이에요.        │ │
│ │ 문장 해석                 │ │  해석 (해석이 있는 문항만)
│ │ 목요일로 회의를 미루죠.   │ │
│ └──────────────────────────┘ │
│ [        다음 문제         ]  │  마지막 문제면 "결과 보기"
```

| 상태 | 선택지 | 해설·해석·버튼 |
|------|--------|----------------|
| 답하기 전 | 모두 클릭 가능 | 숨김 |
| 답한 후 | 모두 비활성, 정답 초록, 고른 오답 빨강 | 표시 |

- 태그: 분류(개발자 영어/직장 영어/학교 영어/토익 대비/일상 영어)와 난이도(기초/중급/심화)
- 문장 해석은 정답을 알려 주므로 답하기 전에는 없다. 틀린 문제(S-04)·다시 볼 항목·오늘의 문제 복습(S-05)에도 해설 아래에 같은 모양으로 나온다.
- 다시 열었을 때: 답하지 않은 첫 문제부터 보여 준다. 5문제를 다 답했지만 결과를 안 봤으면 5번 문제의 답한 후 상태로 보여 준다.

## S-03. 오늘 완료 [구현]

```
┌──────────────────────────────┐
│ 오늘 학습을 마쳤어요           │
│    4 / 5          +45         │
│  맞힌 문제       획득 XP       │
│ 새 문제는 내일 열려요.         │
└──────────────────────────────┘
```

## S-05. 오늘의 문제 복습 [구현]

```
← 홈으로
오늘의 문제 복습
5문제 중 4문제를 맞혔어요.
┌──────────────────────────────┐
│ 1번 ✗ 틀림                    │
│ Let's push back the meeting   │
│ to Thursday.                  │
│ 내 답 put on   정답 push back │
│ 'push back'은 일정을 …        │
│ 문장 해석: 목요일로 회의를 …  │
│ [문장 저장] [단어 저장]        │
└──────────────────────────────┘
… (5문제)
```

- 결과 화면(S-03)의 "오늘 문제 다시 보기"로 들어온다. 들어오면 제목에 포커스가 간다.
- 맞힘·틀림은 색과 함께 글자·기호로 표시하고, 각 문제는 제목(h2)이라 스크린리더로 문제 단위 이동이 된다.

## S-04. 틀린 문제 [구현]

- 홈 메뉴 "틀린 문제 N개"로 들어온다 (F-08).
- 문제마다 그때 고른 답과 날짜, 보기 4개. 다시 풀면 정답 표시와 함께 해설·문장 해석이 나온다.
- 맞히면 "이번에는 맞혔어요. 목록에서 빠져요."와 "확인" 버튼. 틀리면 "다시 틀렸어요. 정답은 ○○예요."

## 화면 전환

| 출발 | 조건 | 도착 |
|------|------|------|
| 진입 | 오늘 미완료 | S-01 + S-02 (1번) |
| 진입 | 오늘 완료 | S-01 + S-03 |
| S-02 | "다음 문제" | S-02 (다음 번호) |
| S-02 | "결과 보기" | S-01 갱신 + S-03 |

## 로딩

저장소와 오늘 날짜를 읽기 전에는 아무것도 그리지 않는다. 빌드 시점 HTML과 실제 상태가 달라 생기는 깜빡임을 막기 위해서다.

## 앱인토스 공통 요소

- 상단 내비게이션 바는 앱인토스가 그린다 (`apps-in-toss.config.ts`의 `navigationBar`: 뒤로가기, 제목, 라이트 테마).
- 기본은 라이트 모드다. 고대비·어둡게는 S-00에서 고를 때 적용된다.
