# 06. Design System

밝은 회색 배경, 흰 카드에 웜 오렌지 주요 색을 쓴다. "밥을 챙겨 먹듯 영어 한 입" 컨셉에 맞춘 색이고, 토스 브랜드 컬러(토스 블루 계열)는 쓰지 않는다 (앱인토스 플러그인 브랜드 가드, `contrast.test.ts`가 검사). 모든 값은 `src/app/globals.css`의 CSS 변수로 관리한다.

## 1. 색상 토큰

| 토큰 | 용도 | 값 |
|------|------|----|
| `--bg` | 페이지 배경 | `#f4f5f7` |
| `--card` | 카드, 선택지 배경 | `#ffffff` |
| `--text` | 본문 | `#191f28` |
| `--sub` | 보조 텍스트 | `#4e5968` |
| `--line` | 테두리, 진행 바 바탕 | `#d1d6db` |
| `--primary` | 브랜드 색(로고 배경). 앱인토스 설정 `brand.primaryColor`와 같음. 글자·버튼 배경에는 쓰지 않음 | `#ea580c` |
| `--primary-strong` | 주요 버튼 배경, 진행 바, 태그 글자 | `#c2410c` |
| `--primary-soft` | 태그·해설 배경 | `#fff1e6` |
| `--ok` / `--ok-soft` | 정답 테두리·글자 / 배경 | `#0e7c55` / `#e3f7ee` |
| `--bad` / `--bad-soft` | 오답 테두리·글자 / 배경 | `#d22030` / `#ffeaec` |
| `--focus` | 포커스 테두리 | `#191f28` |

모든 글자 색은 배경 대비 4.5:1 이상이다. `src/app/contrast.test.ts`가 검사한다 ([17_접근성](17_접근성.md)).

위 값은 기본 모드다. `:root[data-theme='contrast']`, `:root[data-theme='dark']`에서 같은 토큰을 다시 정의한다.

| 토큰 | 고대비 | 어둡게 |
|------|--------|--------|
| `--bg` / `--card` | `#ffffff` / `#ffffff` | `#1a1c20` / `#24272d` |
| `--text` / `--sub` | `#000000` / `#24292f` | `#e6e8eb` / `#b0b8c1` |
| `--line` | `#000000` | `#4a4f58` |
| `--primary-strong` / `--on-primary` | `#9a3412` / `#ffffff` | `#fdba74` / `#10131a` |
| `--primary-soft` | `#ffffff` | `#3a2414` |
| `--ok` / `--ok-soft` | `#005c38` / `#eefaf4` | `#7ee2b8` / `#16332a` |
| `--bad` / `--bad-soft` | `#9b0016` / `#fff0f1` | `#ffa3ab` / `#3a1d22` |
| `--track` (진행 바 바탕) | `#ffffff` + 검정 테두리 | `#4a4f58` |
| `--border-width` | `2px` (정답·오답 선택지 3px) | `1px` |

- 기본은 라이트다. 기기 다크 모드(`prefers-color-scheme`)는 따르지 않는다 (앱인토스 출시 가이드).
- 고대비는 기기 "대비 높이기"를 따를 수 있고, 어둡게는 사용자가 고를 때만 켠다. 이유와 대상은 [17_접근성](17_접근성.md) 2장.

## 2. 타이포그래피

| 요소 | 크기 | 굵기 |
|------|------|------|
| 페이지 제목 `h1` | 22px | 기본(bold) |
| 레벨 숫자 `.level` | 28px | 700 |
| 문제 문장 `.prompt` | 20px | 600 |
| 본문, 선택지 | 16px (기본) | 400 |
| 보조 `.sub` | 14px | 400 |
| 진행 단계 `.step`, 태그 `.tag` | 13px / 12px | 400 |

- 글꼴: 시스템 글꼴 우선, Pretendard → Apple SD Gothic Neo → Noto Sans KR
- 한국어 문장은 `word-break: keep-all`로 단어 중간에서 줄바꿈하지 않는다.

## 4. 컴포넌트

| 클래스 | 설명 | 상태 |
|--------|------|------|
| `.card` | 흰 배경 카드 | - |
| `.bar` | 레벨 진행 바, 안쪽 div 너비로 비율 표시 | 너비 0.3s 전환 |
| `.tag` | 문제 분류(개발자/직장/학교/토익/일상)와 난이도(기초/중급/심화) 라벨 | - |
| `.choice` | 선택지 버튼, 최소 높이 3rem | 기본 / `.ok` 정답("✓ 정답") / `.bad` 고른 오답("✗ 내 선택") / `aria-disabled` |
| `.sr-only` | 화면에는 숨기고 스크린리더에는 읽히는 글자 | - |
| `.theme-picker` | 화면 모드 라디오 묶음 (기본 / 고대비 / 어둡게) | 선택됨: 2px 테두리 + "✓" |
| `.explain` | 해설 박스 | - |
| `.translation` | 해설 아래 문장 해석. 위에 `.translation-label`("문장 해석", 보조색 13px 굵게) | 해석이 없는 문항은 그리지 않음 |
| `.btn` | 화면 폭 전체 주요 버튼 | - |
| `.stats` | 결과 화면 수치 2칸 | - |

## 5. 문구 원칙

- 해요체를 쓴다. 예: "오늘 학습을 마쳤어요"
- 실패를 강조하지 않는다. 오답 수 대신 "맞힌 문제"를 보여 준다.
